SPIC ONE-ன் மற்ற திரைகள் பயன்படுத்தும் அடிப்படைப் பட்டியல்களை இந்தத் திரைகள் வைத்திருக்கின்றன: ஊழியர்களும் அவர்களின் லாகினும், டெசிக்னேஷன்கள் (ஒவ்வொருவரும் எந்தப் பக்கங்களைத் திறக்கலாம்), இடங்கள், பயிர்கள் மற்றும் product-கள், வங்கிகள், சில செட்டிங்குகள். இவற்றில் பெரும்பாலானவை எளிய பட்டியல்கள்தான்: ஒரு பதிவைச் சேர்க்கலாம், திருத்தலாம், ஆன் அல்லது ஆஃப் செய்யலாம்.

**இந்தத் திரை எதற்கு**
**Employee Management** திரையில் ஒவ்வொரு ஊழியரின் லாகினும் அவர்களின் ரோல் மற்றும் மாநிலத்துடன் தெரியும். இங்கிருந்து புதிய ஊழியர்களைப் பதிவு செய்யலாம், பலரை ஒரே நேரத்தில் அப்லோட் செய்யலாம், அல்லது ஒரு லாகினைத் திருத்தலாம், நீக்கலாம்.

1. **Employee List**-ல் ஒரு ஊழியரைக் கண்டுபிடிக்க தேடல் பெட்டி, **All Role**, **All States** ஆகியவற்றைப் பயன்படுத்துங்கள்.
2. நெடுவரிசைகளைப் படியுங்கள்: **Employee ID**, **Name**, **User Name**, **Password**, **Role** மற்றும் **State**.

2. **Tables**-ல், ஒரு அட்டவணையைத் தேடித் தேர்வு செய்யுங்கள். **Filter (any column contains)**-ல் டைப் செய்து Enter அழுத்துங்கள். வரிசைப்படுத்த ஒரு நெடுவரிசைப் பெயரைத் தட்டுங்கள்.
3. ஒரு வரிசையைத் திருத்த அதைத் தட்டி, பிறகு **Save** அல்லது **Delete** அழுத்துங்கள். ஒரு வரிசையைச் சேர்க்க **New row**, பிறகு **Insert** அழுத்துங்கள். **Export CSV** வரிசைகளைப் பதிவிறக்கும்.
4. **Query**-ல், ஒரு SQL கட்டளையை டைப் செய்து **Run** அழுத்துங்கள். மாற்றம் என்றால் முதலில் ஒரு சோதனை ஓட்டம் (dry run) காட்டும்; அதைச் செயல்படுத்த **Confirm: change ... row(s)** அழுத்துங்கள்.
5. கடைசி மாற்றங்களைப் பார்க்க **Audit log**-ஐத் திறங்கள். முடித்ததும் **Lock** அழுத்துங்கள்.

> Careful: இங்கே செய்யும் மாற்றங்கள் நேரடியாக லைவ் தரவுக்குப் போகும், அவற்றைத் திரும்பப் பெற முடியாது. முடிந்தவரை வழக்கமான திரைகளையே பயன்படுத்துங்கள்.
